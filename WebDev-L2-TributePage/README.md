# Dr. A. P. J. Abdul Kalam Tribute Page

A responsive and visually appealing tribute webpage dedicated to **Dr. A. P. J. Abdul Kalam**, one of India's most respected scientists, authors, and former presidents.

## About the Project

This project presents information about Dr. A. P. J. Abdul Kalam, including:

- His early life and education
- Career as a scientist
- Contributions to India's space and missile programmes
- Career as the 11th President of India
- Awards and honours
- Books and contributions as an author
- Vision for India's future
- Famous quote

## Features

- Responsive design for desktop, tablet, and mobile devices
- Clean card-based layout
- Different gradient colors for each information section
- Attractive header with decorative elements
- Serif font for headings
- Sans-serif font for regular text
- Hover animation effects on content sections
- Styled quote section
- Accessible image alternative text
- External Wikipedia link for additional information

## Technologies Used

- HTML5
- CSS3
- Google Fonts
  - Nunito
  - Playfair Display

## Design

The webpage uses:

- **Playfair Display** for headings and the famous quote
- **Nunito** for paragraphs, lists, captions, and other text
- Navy and teal colors for the header and footer
- Individual gradient backgrounds for different sections
- Gold accents for important highlights
- Rounded cards and shadows for a modern appearance

## How to Run

1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click the file and select **Open with Live Server**.

You can also open `index.html` directly in any modern web browser.
